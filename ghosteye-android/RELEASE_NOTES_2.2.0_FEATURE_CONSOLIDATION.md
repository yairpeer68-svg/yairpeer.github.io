# Ghost Eye Phone 2.2.0 — Feature Consolidation

- Adds a unified Security Posture card to target scan results.
- Shows exposure score, open/sensitive services, CVE/KEV counts, and top priorities in one place.
- Keeps screenshot capture enabled on normal screens; secure-window protection remains scoped to secret/password entry.
- Includes a Windows 11 one-click release APK builder.
- Remains compatible with older scan payloads: the Security Posture card simply stays hidden when the server does not provide it.
