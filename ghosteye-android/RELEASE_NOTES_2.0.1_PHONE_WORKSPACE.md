# Ghost Eye Phone 2.0.1 — Intelligence Workspace

This release turns the Android client into a focused intelligence workspace with five primary areas:

- Investigate — persistent Intelligence Fabric v2 execution for domain/IP/URL/hash/ASN/CVE/package.
- Graph — global entity memory, relationship exploration, timeline and watchlist pivoting.
- CVE — live vulnerability correlation across the server's vulnerability intelligence layer.
- Watchtower — watchlist creation, alert review and refresh.
- Sources — OSINT/provider environment and secure provider vault management.

Existing History and Investigations remain available from the top bar.

Safety posture is unchanged: the mobile workflow defaults to passive external intelligence; provider submissions remain opt-in and direct origin probing/active exploitation are not introduced by this release.
