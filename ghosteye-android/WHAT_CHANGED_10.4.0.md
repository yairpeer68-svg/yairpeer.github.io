# Ghost Eye Phone 10.4.0 — Deep Intelligence

- Keeps the clean two-action experience: **File** and **Domain / IP**.
- Domain/IP stays one-tap: enter one authorized target and press **Scan All**; no module-selection clutter.
- **Scan Again & Compare** repeats the complete current server scan and shows what actually changed.
- Smart results prioritize risk, findings and useful infrastructure data instead of raw IDs, hashes, debug objects or pipeline dumps.
- Adds in-result search, attack-surface summary, priority insights and a compact Hebrew intelligence summary.
- Adds a target timeline and a readable relationship map for Domain → IP → DNS/certificate/service relationships.
- Adds opt-in **Daily Watch** from the result screen. Turning it off deletes the watch; deleting one historical scan does not silently disable the watch.
- Adds signed-report creation, immediate signature verification and report deletion from both target and file results.
- Keeps scan/analysis deletion controls and hides server endpoint details from the visible UI.
- Android `versionCode 21` / `versionName 10.4.0`; Java/Kotlin bytecode target remains 17 while the Windows build uses JDK 21.
