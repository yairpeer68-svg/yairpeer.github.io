# Ghost Eye Phone 10.2.0

## Results
- Full intelligence results are visible in the current analysis and History: risk, all findings, all evidence, metadata, module output, entities, relationships, pipeline and integrity.
- Signed reports can be created, verified and deleted.

## Target Intelligence
- New dedicated **סריקה** category for an authorized public Domain / IP / URL.
- Select one module, multiple modules, or ALL.
- Modules: DNS, reverse DNS, TLS, HTTP, security headers, technology, common ports, redirects, local reputation and optional AI.
- Private, loopback, link-local and reserved targets are blocked server-side.

## Privacy & branding
- The server address is no longer displayed anywhere in the Android UI.
- The full owner email is not packaged in the app; only the masked account label is shown.
- New Ghost Eye eye/shield branding is used for launcher, splash, login and the main header.

## Data management
- Delete individual analyses/scans, projects, cases, signed reports and audit entries with confirmation.
- Local crash logs remain deletable from Settings.
