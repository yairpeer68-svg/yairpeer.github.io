# Ghost Eye Phone 10.5.0 — File Intelligence Pro

- File analysis remains one clean action: choose a file and tap **נתח את כל המידע**.
- Added a concise capability/behavior card instead of raw analyzer output.
- Added a dedicated IOC/communication card for domains, URLs, IPs and API paths.
- Added component/security summary: SBOM components, redacted secret count, packing/obfuscation hints and exact CVE matches when a server catalog is configured.
- Added automatic version comparison against the previous completed analysis with the same filename.
- Added similarity/history summary for related artifacts.
- Search now applies to both target and file-intelligence results.
- Server address remains hidden from visible UI.
- Existing two-tab UI remains: **קובץ** and **דומיין**.
- Version: 10.5.0 (`versionCode 22`).
- Added a safe file→domain/IP pivot: an extracted infrastructure indicator can be copied into the Domain tab, but network activity still requires explicit authorization and **סרוק הכל**.
