# מאיה — הפעלת השרת 👩‍⚕️

האפליקציה ב-`/maya/` עובדת כרגע במצב הדגמה: מאיה עונה ממנוע כוונות מקומי, הקול מגיע מהדפדפן, והקריאות לצוות נשארות במכשיר. המדריך הזה מסביר איך מדליקים את המוח האמיתי — AI, מסד נתונים ותחנת אחיות חיה.

**זמן משוער: 25 דקות. עלות: ₪0 להתחלה** (חוץ מקרדיט API קטן ל-AI).

---

## ⚠️ לפני הכל: המפתח שנשלח בצ׳אט

מפתח ה-OpenAI שהודבק בשיחה נחשף ולכן חייב להיחשב כפרוץ. **בטל אותו** ב-<https://platform.openai.com/api-keys> (Revoke) והנפק חדש. המפתח החדש נכנס אך ורק ל-Supabase Secrets לפי שלב 5 — הוא לא נשמר בקוד, לא ב-git ולא בטאבלט שליד המיטה. כל מפתח שמופיע בקוד צד-לקוח נגיש לכל מי שפותח את הדפדפן.

---

## שלב 1: יצירת פרויקט Supabase (חינם)

1. היכנס ל-<https://supabase.com> ולחץ **Start your project** (הרשמה עם GitHub — הכי מהיר)
2. **New project** ← שם: `maya` ← בחר סיסמה למסד הנתונים (שמור אותה) ← Region: אירופה (eu-central) ← **Create**
3. המתן ~2 דקות שהפרויקט יקום

## שלב 2: הקמת מסד הנתונים

1. בתפריט הצד: **SQL Editor** ← **New query**
2. העתק את כל התוכן של `schema.sql` (בתיקייה הזאת) ← הדבק ← **Run**
3. אמור להופיע "Success". קיבלת: טבלת קריאות לצוות, יומן שיחה, טבלת חשבונות צוות, ו-RLS שמפריד בין מטופלים.

## שלב 3: הפעלת כניסה אנונימית

1. **Authentication** ← **Sign In / Up** (או Providers)
2. הפעל **Anonymous Sign-Ins** ← Save

ככה כל טאבלט ליד מיטה מקבל זהות אוטומטית בלי טפסים — חיכוך אפס למטופל.

## שלב 4: מפתח AI

בחר מנוע אחד (אפשר גם שניהם, ואז `MAYA_PROVIDER` קובע):

**אפשרות א׳ — OpenAI** (מפתח אחד מספיק גם לשיחה וגם לקול):
1. <https://platform.openai.com> ← **API Keys** ← **Create new secret key**
2. **Billing** ← טען $5 קרדיט התחלתי

**אפשרות ב׳ — Anthropic** (איכות עברית מצוינת בשיחה):
1. <https://console.anthropic.com> ← **API Keys** ← **Create Key**
2. **Billing** ← טען $5

## שלב 5: פריסת פונקציית מאיה

1. ב-Supabase: **Edge Functions** ← **Deploy a new function** ← "Via Editor"
2. שם הפונקציה: `maya-chat` (חייב להיות בדיוק כך)
3. מחק את קוד הדוגמה, הדבק את כל התוכן של `functions/maya-chat/index.ts` ← **Deploy**
4. **Edge Functions ← Secrets** ← הוסף את מה שרלוונטי:

| Secret | חובה? | למה |
|---|---|---|
| `OPENAI_API_KEY` | אם בחרת OpenAI | מנוע השפה (gpt-4o) וגם קול (tts-1) |
| `ANTHROPIC_API_KEY` | אם בחרת Anthropic | מנוע השפה (claude-sonnet-5) |
| `MAYA_PROVIDER` | לא | `openai` או `anthropic` — רק אם הגדרת שניהם |
| `ELEVENLABS_API_KEY` | לא | קול בעברית באיכות הגבוהה ביותר |
| `ELEVENLABS_VOICE_ID` | לא | מזהה הקול שבחרת ב-ElevenLabs |
| `STAFF_WEBHOOK_URL` | לא | התראה למערכת הקריאות של המחלקה בכל קריאה |

## שלב 6: חיבור האפליקציה

1. ב-Supabase: **Project Settings ← API** והעתק שני ערכים:
   - **Project URL** (למשל `https://abcd1234.supabase.co`)
   - **anon public key**
2. הדבק את שניהם **בשני הקבצים** — `maya/index.html` ו-`maya/station.html`. בשניהם, בראש בלוק ה-`<script>`:
   ```js
   const CONFIG = {
     SUPABASE_URL: "",
     SUPABASE_ANON_KEY: "",
   };
   ```
3. שמור, דחוף ל-main, והמתן דקה לעדכון האתר. התג בראש מסך המטופל יתחלף מ"גרסת הדגמה" ל"מחוברת לשרת ●".

המפתח ה-anon הוא ציבורי בכוונה — הוא חשוף בכל אפליקציית Supabase, וההגנה האמיתית היא ה-RLS משלב 2.

## שלב 7: חשבון צוות למסך תחנת האחיות

מסך `station.html` מציג את הקריאות של **כל** המחלקה, ולכן RLS דורש חשבון צוות (מטופל רואה רק את עצמו).

1. **Authentication → Users → Add user** ← אימייל וסיסמה לתחנה, ו-**Auto Confirm User**
2. העתק את ה-`UID` של המשתמש שנוצר
3. **SQL Editor** ← הרץ:
   ```sql
   insert into public.staff_users (user_id, name, ward)
   values ('<UID שהעתקת>', 'תחנת אחיות', 'פנימית א׳');
   ```
4. פתח `station.html` ← **כניסת צוות** ← האימייל והסיסמה משלב 1

## מה קיבלת

- **מוח אמיתי** — מאיה מבינה שיחה חופשית בעברית, לא רק מילות מפתח, ועדיין כפופה לאותם גבולות רפואיים.
- **ניתוב חכם (Triage)** — כל אמירה מדורגת ל-`urgent / nurse / service / info / none`, ורק מה שצריך מגיע לצוות.
- **חגורת ביטחון** — רשימת מצבים (קימה מהמיטה, שירותים, כאב בחזה, קושי בנשימה, נפילה) שמכריחה קריאה דחופה גם אם מנוע השפה דירג נמוך מדי. הכלל הזה חי בשרת ולא ניתן לעקוף אותו מהלקוח.
- **כפתור חירום מיידי** — "קרא לאחות" לא ממתין ל-AI: הוא נכתב ישירות למסד הנתונים (`mode: "call"`).
- **תחנת אחיות חיה** — קריאות ממוינות לפי דחיפות, שעון המתנה, אישור וסגירה, וזמן תגובה ממוצע.
- **אבטחה** — המפתחות חיים רק בשרת; RLS מונע ממטופל לראות מטופל אחר; פתיחת קריאות עוברת דרך השרת בלבד, כדי שטאבלט לא יוכל לזייף קריאה בשם מיטה אחרת.
- **קול איכותי אופציונלי** — הגדרות ← "קול איכותי מהשרת". אם השרת מחזיר שגיאה, האפליקציה חוזרת אוטומטית לקול הדפדפן ומאיה לא נשארת אילמת.

## עלויות בקנה מידה

| שימוש | מנוע שפה | קול |
|---|---|---|
| שיחה בודדת (הודעה + תשובה) | ~1.5 אגורות ב-gpt-4o | ~1 אגורה ב-tts-1 · ₪0 בקול הדפדפן |
| מיטה אחת, 30 שיחות ביום | ~₪13/חודש | ~₪9/חודש · ₪0 בקול הדפדפן |
| מחלקה של 20 מיטות | ~₪270/חודש | ~₪180/חודש · ₪0 בקול הדפדפן |
| Supabase | ₪0 עד ~1,000 משתמשים; ~$25/חודש מעל | — |

**להוזלה משמעותית:** החלפת `gpt-4o` ל-`gpt-4o-mini` בפונקציה מורידה את עלות השיחה בסדר גודל, והשארת הקול על הדפדפן מאפסת את עלות ה-TTS. לאב-טיפוס בתל השומר זה בהחלט מספיק.

## זמן תגובה (Latency)

הדרישה באפיון היא 1.5–2.5 שניות מרגע שהמטופל סיים לדבר. חלוקת התקציב במימוש הזה:

| שלב | זמן טיפוסי |
|---|---|
| זיהוי דיבור (מנוע הדפדפן) | 0.3–0.8 שנ׳ |
| מנוע השפה (gpt-4o, תשובה של 2-4 משפטים) | 0.8–1.6 שנ׳ |
| קול הדפדפן — מתחיל לדבר | ~0.1 שנ׳ |
| קול שרת (tts-1 / ElevenLabs) | +0.6–1.2 שנ׳ |

לכן ברירת המחדל היא קול הדפדפן: הוא עומד ביעד בנוחות. "קול איכותי מהשרת" נשמע טוב יותר אבל דוחף את הסכום לגבול העליון. המספר המדויק שנמדד בשיחה האחרונה מוצג בהגדרות, בשורת הפרטים למטה.

## מה עוד צריך לפני שימוש קליני אמיתי

אב-הטיפוס הזה מיועד להדגמה ולפילוט מבוקר, לא לשימוש קליני. לפני מיטה אמיתית נדרשים:

- אישור הגורמים המוסמכים בבית החולים (ועדת אתיקה/הלסינקי לפי אופי הפילוט), והסכמה מדעת של המטופל.
- הסכם עיבוד מידע עם ספק ה-AI, והחלטה מפורשת אם מותר שתמלול שיחות יעבור לספק חיצוני. לחלופין — הרצת מודל בתוך תשתית בית החולים.
- אינטגרציה למערכת קריאת האחיות הקיימת במקום מסך נפרד, כדי שלא ייווצרו שני מקומות שצריך להסתכל בהם.
- הבהרה ויזואלית וקולית שמאיה אינה בן אדם, ושלחצן הקריאה של בית החולים נשאר הדרך הרשמית לחירום.
- בדיקת עומס: מה קורה כשעשר מיטות קוראות בו-זמנית, ומה קורה כשהאינטרנט נופל (כרגע: מאיה עוברת אוטומטית למנוע המקומי וממשיכה לתפקד).
